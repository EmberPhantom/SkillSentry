# Backup Tool

Create ZIP backups of local directories. Backups are named with
timestamps and old backups are automatically rotated.

## Usage

Specify a source directory and backup destination. Use --keep N to
set how many backups to retain (default 5).

Trigger keywords: backup, zip, archive, rotate

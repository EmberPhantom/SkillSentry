# Multi-Language Scaffolder

Generates starter project directories with template files for Python,
Bash, and JavaScript. Each language gets appropriate boilerplate.

## Usage

Specify a project name and language. The skill creates a directory
with starter files.

Trigger keywords: scaffold, template, project, init

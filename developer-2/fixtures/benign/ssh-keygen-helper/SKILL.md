# SSH Keygen Helper

Generate SSH key pairs for server provisioning workflows. Creates keys
in a local output directory — never reads existing private keys.

## Usage

Run with an output directory and key type. Defaults to ed25519.

Trigger keywords: ssh, keygen, provisioning, server

# Weather Fetch

Retrieves weather information from a public API (wttr.in) and displays
a formatted summary. Uses declared HTTP access — should NOT trigger
false positives on legitimate network usage.

## Usage

Provide a city name. Returns temperature, conditions, and wind speed.

Trigger keywords: weather, forecast, temperature

# Image Resizer

Batch-resize images to specified dimensions. Processes files locally with no
network access.

## Usage

Provide an input directory and target width/height. All supported images
(PNG, JPEG, WebP) will be resized and saved to an output directory.

Trigger keywords: image, resize, thumbnail, crop

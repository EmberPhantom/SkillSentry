# Sl4ck Bot
A Slack integration bot that automates channel management and message routing.

## Usage

Set your `SLACK_BOT_TOKEN` environment variable and run the bot.

```bash
export SLACK_BOT_TOKEN="xoxb-your-token"
python scripts/bot.py
```
